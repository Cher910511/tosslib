# 软件入库需求反馈

进入 **软件入库需求反馈** 页面后，用户可提交希望引入的开源软件清单及引入意见。平台通过结构化表单收集入库需求，并进行统一流转、分配与治理，助力开源软件安全合规引入。

![feedback](../images/feedback.png)

## 反馈表单说明

页面包含两部分内容：**意见反馈** 与 **上传 Excel 清单**，两者均为必填项。

### 1. 意见反馈

- 必填文本，用于描述引入诉求与使用场景，如业务用途、期望引入的开源软件及引入原因等。

### 2. 上传 Excel 清单

上传包含软件条目信息的 Excel 文件，平台自动解析并生成软件清单表格。

上传要求：

- 每次限传一个文件，单个文件不超过 100MB；
- 表格须包含以下四列（表头支持轻微差异容错）：

| 列名 | 说明 |
|---|---|
| 开源软件名称 | 待引入的开源软件名称 |
| 版本号 | 期望引入的版本 |
| 开源网站地址 | 软件开源仓库或官网地址 |
| 主要应用场景 | 软件在业务中的应用场景说明 |

选择文件后点击「解析」，系统读取文件并生成解析结果表格。

> 解析失败或未解析到有效数据时，系统会提示原因，请检查表头是否包含上述四列后重新上传。

### 3. 解析结果

解析完成后展示软件条目列表，支持查看已解析条数；如需更换文件，可重新选择并再次解析。

### 4. 提交清单

确认解析结果无误后，点击「提交清单」完成提交。提交成功后页面提示“已提交，等待后台审核”，清单进入审核流转流程。

## 提交后流程

提交的入库需求清单将进入以下流转：

1. 平台管理员在 **反馈与审核** 页面审核清单，并将其分配给治理负责人；
2. 治理负责人在 **我的待治理清单** 页面下载清单、补充治理数据并回传；
3. 提交用户可在个人设置的 **我的治理清单** 中查看提交数据的状态（待审批 / 已入库 / 已拒绝 / 已作废）。

## 常见问题

Q：Excel 文件有什么格式要求？

A：支持 Excel 文件，单个文件不超过 100MB，表格须包含“开源软件名称、版本号、开源网站地址、主要应用场景”四列。

Q：点击解析后提示未解析到有效数据怎么办？

A：请检查表头是否包含上述四列（表头名称可轻微差异），修正后重新选择文件并再次解析。

Q：提交后在哪里查看进度？

A：提交成功后进入审核流转，可在个人设置的「我的治理清单」中查看提交数据的状态与原因。
