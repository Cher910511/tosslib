# 签名验证

进入 **签名验证** 页面后，用户可上传从平台下载的源码包或组件包，通过签名校验验证下载来源的真实性，并结合安全检测评估软件可信度，确认文件是否为平台下载的原始文件。

## 功能概述

平台下发的源码包、组件包均带有平台签名。将待验证的文件上传至签名验证页面，平台将自动校验文件签名与安全状态：

- **签名状态**：校验文件签名是否有效，是否为平台签发；
- **可信状态**：结合安全检测结果评估软件是否可信。

两项均通过时，判定该文件为平台下载且可信的文件。

## 验证流程

签名验证分为三步：

```text
上传文件
  → 扫描文件
    → 查看结果
```

### 1、上传文件

点击上传区域或拖拽文件到指定区域，选择后自动上传至平台。

- 支持格式：zip、tar、gz、bz2、rar、7z 等；
- 单文件不超过 96MB；
- 上传成功后显示“上传完成，可提交验证”。

> 上传完成后点击「提交验证」即可开始扫描；如需更换文件，可先清空再重新选择。

### 2、扫描文件

平台正在分析上传的安装包，此阶段无需操作，请稍候。

### 3、查看结果

扫描完成后展示验证结果：

| 结果项 | 说明 |
|---|---|
| 验证通过 | 该文件签名有效且软件可信，可放心使用 |
| 验证未通过 | 该文件签名无效或软件未通过可信验证，建议从可信渠道重新下载 |

结果区同时展示文件名称、验证时间、签名状态（通过 / 未通过）与可信状态（可信 / 不可信）。

验证完成后可点击「验证其他文件」继续验证。

## 常见问题

Q：为什么提示验证未通过？

A：可能原因包括：文件签名无效（非平台下载或下载过程中被篡改）、文件不完整，或软件未通过安全可信验证。建议从平台可信渠道重新下载后再验证。

Q：支持哪些文件格式？

A：支持 zip、tar、gz、bz2、rar、7z 等常见压缩包格式，单文件不超过 96MB。

Q：上传后一直没有反应怎么办？

A：请确认文件大小是否超出限制、文件格式是否支持；如仍异常，可清空后重新选择并提交验证。
