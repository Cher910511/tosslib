## 一、可信开源的定义

**可信开源（Trusted Open Source）** 是指经过代码库安全性、合规性、供应链完整性与社区可持续性等多维度评估，符合代码库可信开源评价标准的开源软件。具体包含但不限于以下维度：

1. **安全可信：** 代码及其依赖链经过静态扫描、漏洞检测、恶意代码分析，不存在已知高危漏洞、恶意投毒或后门风险，或相关风险已修复并持续跟踪；
2. **来源可信：** 代码来源可溯源、可验证，具备完整的版本谱系与签名/哈希校验机制，未被篡改或污染；
3. **许可合规：** 开源许可证经合规性审查，不存在传染性许可证冲突或其他知识产权风险；
4. **供应链可信：** 项目上游依赖、维护团队、发布流程可信可控，符合软件供应链安全相关要求；
5. **持续治理：** 项目有活跃维护或有稳定的治理机制，关键漏洞与安全更新可获得持续响应。

> **特别说明：** “可信”评级系代码库基于当时可获得的信息、评估方法和工具所作的专业判断，不代表该代码“绝对安全”或“无任何缺陷”，亦不构成代码库对任何用户使用后果的保证。

1. **可信开源代码检索与浏览：** 提供经评估的开源项目、组件信息的查询、浏览与比对；
2. **可信代码托管与下载：** 提供可信组件的版本下载和完整性校验；
3. **代码安全检测服务：** 提供开源组件的漏洞扫描、依赖分析（SCA）、许可证合规检查等检测能力；
4. **可信评估报告：** 提供组件安全评估、供应链风险评估及相关报告服务；
