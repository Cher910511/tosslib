# 组织工作台 - 需求文档

## 1. 概述

组织工作台（OrgDashboardTab）是组织详情页的默认首页，面向组织管理员提供全局治理概览。页面聚合了安全风险、版本火车、软件资产、预警信息等核心指标，帮助管理员快速掌握组织整体治理状况。

### 1.1 角色权限

| 角色 | 权限 |
|------|------|
| 平台超级管理员 | 可查看所有组织的完整数据 |
| 组织管理员 | 可查看本组织工作台 |
| 普通成员 | 无权限访问（显示"仅组织管理员可查看工作台"） |

### 1.2 页面结构

```
┌─────────────────────────────────────────────────────┐
│ KPI 指标行 (5 张卡片)                                │
├─────────────────────────────────────────────────────┤
│ 版本火车状态堆叠条 + 图例                             │
├────────────────────────┬────────────────────────────┤
│ 风险等级分布 (环形图)    │ 漏洞软件排行 TOP 10         │
│                        │ (两列网格，含已下架筛选)     │
├──────────┬─────────────┬────────────────────────────┤
│ 软件与    │ 近 30 天    │ 最新预警 (5 条)             │
│ 组件概况  │ 预警趋势     │ + 查看详情跳转              │
│ (柱状图)  │ (折线+滑块)  │                            │
└──────────┴─────────────┴────────────────────────────┘
```

## 2. 功能区详述

### 2.1 KPI 指标行

展示组织核心运营指标，共 5 张卡片：

| 卡片 | 数值 | 说明 |
|------|------|------|
| 使用中的软件 | 128 | 当前组织在用的软件总数 |
| 使用中的组件 | 356 | 当前组织在用的组件总数 |
| 下架软件 | 12 | 已下架的软件数量 |
| 下架组件 | 45 | 已下架的组件数量 |
| 本周新增预警 | 6 | 本周新产生的漏洞预警数 |

- 每个卡片包含图标、数值、标签和变化趋势脚注
- 下架类数字用红色标识（`dash-stat-value--danger`）
- 变化趋势用绿色（上升）、灰色（持平）、红色（下降）区分

### 2.2 版本火车状态堆叠条

以水平堆叠条形式展示组织中所有版本火车的状态分布：

| 状态 | 颜色 | 说明 |
|------|------|------|
| 已发车 | 🟢 绿色 (#22c55e) | 已发布且在有效期内的火车 |
| 待发车 | 🟡 琥珀色 (#f59e0b) | 已创建但尚未发布的火车 |
| 已过期 | ⚪ 灰色 (#9ca3af) | 已过有效期的火车 |

- 使用纯 CSS 实现，三段宽度按比例计算（`33.33% / 33.33% / 33.34%`）
- 每段内含白色文字标签（如"已发车 4"）
- 下方独立一行展示圆点图例
- 标题行显示总数量（如"共 12 辆"）

### 2.3 风险等级分布（环形图）

以 ECharts 环形图（donut）展示组织内软件/组件的风险等级分布：

| 等级 | 颜色 | 数据 |
|------|------|------|
| 超危 | 🔴 #7f1d1d | 12 项 |
| 高危 | 🔴 #dc2626 | 28 项 |
| 中危 | 🟡 #f59e0b | 35 项 |
| 低危 | ⚪ #6b7280 | 15 项 |

- 悬停提示显示具体数量和占比
- 标签显示在环形外部
- 4 个扇区按严重程度从深到浅排列

### 2.4 漏洞软件排行

展示组织中漏洞数量最多的软件，帮助管理员快速定位高风险资产：

- **排名列表**：TOP 10，按漏洞数降序排列
- **布局**：两列网格（`grid-auto-flow: column`），左列 1-5 条、右列 6-10 条
- **每行信息**：排名序号 + 软件名称 + 版本号标签（蓝色背景）+ 漏洞数标签（红色药丸）
- **前三名**：🥇🥈🥉 特殊标记（第1名深红、第2-3名橙色）
- **筛选功能**：「包含已下架」复选框，勾选后 Grafana（已下架）插入第 4 位，Vue.js 自动移除，始终保持 10 条

**空数据状态**：
- 显示 🔒 图标 + "暂无漏洞数据" + "该组织暂无存在漏洞的软件"

### 2.5 软件与组件概况

以 ECharts 垂直柱状图展示组织中软件和组件的使用状况：

| 类别 | 使用中 | 已下架 |
|------|--------|--------|
| 软件 | 128 | 12 |
| 组件 | 356 | 45 |

- 蓝色渐变柱（使用中）+ 红色渐变柱（已下架），每组两根并列
- 柱顶显示具体数值
- 底部图例说明
- 悬停提示显示每类合计

### 2.6 近 30 天预警趋势

以 ECharts 折线图展示近 30 天的预警数量变化趋势：

- **折线**：红色 (#da203e)，平滑曲线，圆形数据点
- **面积填充**：红色渐变半透明，从 20% 渐变到 2%
- **横轴**：日期（06-01 至 06-30），7 个采样点
- **纵轴**：预警数量
- **数据缩放**：底部滑块（dataZoom.slider），支持拖拽缩放时间范围
- **滑块样式**：红色主题手柄和填充条

**空数据状态**：
- 显示全零水平线（无数据点、无面积填充）
- 隐藏缩放滑块
- 纵轴固定 max: 10

### 2.7 最新预警

展示最近 5 条漏洞预警信息：

| 字段 | 说明 |
|------|------|
| 风险等级 | 标签样式（超危🔴深红底白字 / 高危🟠红底红字 / 中危🟡黄底橙字） |
| 预警名称 | 漏洞简要描述，溢出省略 |
| 日期 | 预警发布日期 |

- 每条预警占一行，底部有分割线
- 底部「查看详情 →」按钮，点击跳转到「预警信息设置」Tab 页
- 按钮 hover 时显示浅红背景

**空数据状态**：
- 显示 🛡️ 图标 + "暂无预警信息" + "当前组织没有待处理的漏洞预警"

## 3. 数据模型

### 3.1 组织数据

| 字段 | 类型 | 说明 |
|------|------|------|
| org.id | string | 组织唯一标识（如 `org-001`） |
| org.memberCount | number | 成员数量 |
| org.adminCount | number | 管理员数量 |

### 3.2 数据源映射

当前版本数据为前端 Mock，按组织 ID 区分：

| 组织 ID | 组织名称 | 数据状态 |
|---------|----------|----------|
| org-001 | 中国工商银行 | 完整数据 |
| org-002 | 平安科技 | 空数据 |
| org-003 | 华为技术有限公司 | 完整数据 |
| org-004 | 阿里巴巴集团 | 空数据 |

## 4. 交互行为

### 4.1 空数据展示

当组织没有任何预警或漏洞数据时，对应模块应展示友好的空状态占位：

- 空状态图标（🛡️ / 🔒）
- 简要文案说明
- 提示文字

### 4.2 页面跳转

| 操作 | 跳转目标 |
|------|----------|
| 点击「查看详情 →」| 预警信息设置 Tab (`activeTab = 'alerts'`) |

### 4.3 响应式布局

| 屏幕宽度 | 布局调整 |
|----------|----------|
| > 1000px | 5 列 KPI，图表正常排列 |
| 600-1000px | KPI 改为 3 列 |
| < 600px | KPI 改为 2 列，图表改为单列 |

---

## 5. 非功能需求

### 5.1 性能

- ECharts 图表在组件销毁时自动 dispose，避免内存泄漏
- 窗口 resize 时自动调整图表尺寸

### 5.2 技术栈

| 模块 | 技术 |
|------|------|
| 框架 | Vue 3 (Composition API) |
| 图表 | ECharts 5.x |
| 布局 | CSS Flexbox / Grid |
| 构建 | Vite |

### 5.3 图表配置规范

- 所有图表容器固定高度（200px / 180px），超宽图表 220px
- 环形图半径 `['45%', '70%']`
- 折线图平滑曲线 + 面积渐变
- 柱状图使用线性渐变填充
